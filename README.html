What it is

One place for your whole team

One computer in the office becomes the host. Everyone else installs the app, joins with a code and is approved by the owner. Nothing goes to the internet or to any cloud: messages and files travel inside your Wi-Fi at full speed.

1

Chat & voice

Direct messages (end-to-end encrypted), group chats, voice messages, replies, search, seen / not seen ticks, typing indicator.

2

Files at Wi-Fi speed

Send videos and huge files like a local-send app. Uploads resume after a drop, identical files are stored once, versions are kept.

3

Task pipeline

Owner to managers to team leaders to employees and back up: assign, delegate, submit with files, request changes, approve.

4

Team chart & attendance

A tree of who works under whom, plus office hours, check-in, late and absent tracking with a monthly attendance sheet.

5

Work report & records

One sheet with every task and daily update for any period (today to a year, or custom): who, for whom, which client, hours, on time or late, quality, links and files. Plus private sheets. Export to Excel or PDF.

6

Performance

Monthly scores, on-time rate, overdue work, hours logged, 12-month history and manager reviews.

What you need

Every computer

  • Windows 10/11 64-bit, or macOS 12 or newer
  • About 400 MB free disk space for the app
  • Admin permission once, to install

The host computer

  • Stays on during work hours
  • Plenty of free space for the team's files and videos (a drive other than C: is best)
  • Office Wi-Fi or a network cable

The network

  • Everyone on the same Wi-Fi / office network
  • Not a guest network (those block devices from seeing each other)
  • No internet needed after downloading

Install on Windows 10 / 11

  1. Open the Windows folder and double-click Manage-with-Bunny-Setup-1.4.0.exe.
  2. If Windows shows "Windows protected your PC": click More info, then Run anyway (the installer is not code-signed yet, see why).
  3. Press Yes on the "allow this app to make changes" prompt. It installs in a few seconds, adds a desktop and Start-menu shortcut, allows the app through Windows Firewall for your local network only, and opens.
  4. If Windows Firewall still asks, tick Private networks and click Allow.
  5. Continue with First-time setup.

Updating: install the newer setup file over the old one. Your account, settings and all workspace data stay.

Install on macOS 12+

  1. Open the Mac (Apple Silicon) or Mac (Intel) folder and double-click the .dmg.
  2. Drag Manage with Bunny onto the Applications folder, then eject the disk image.
  3. The first time: open Applications, right-click Manage with Bunny, choose Open, then Open again. If macOS still refuses: System Settings, Privacy & Security, scroll down and click Open Anyway.
  4. Allow Local Network access when asked (needed to find the host), Microphone only if you want voice messages, and incoming connections if this Mac will be the host.
  5. Continue with First-time setup.

Updating: drag the new version into Applications and choose Replace. Your data stays.

Uninstall

Remove the app

The workspace data is never deleted automatically. On the host computer the storage folder you chose (messages database, files, videos, backups) stays on the disk so nothing is lost by accident. Delete it yourself only if you are sure, or keep it to host again later ("Host a workspace", "Open existing data folder").

Windows

  1. Quit the app: right-click the bunny icon in the system tray (bottom-right, maybe under the ^ arrow) and choose Quit.
  2. Open Settings, Apps, Installed apps, find Manage with Bunny, click ... and Uninstall (or Control Panel, Programs and Features).
  3. The uninstaller removes the app, its shortcuts, its Windows Firewall rule and its "start with Windows" entry.
  4. Optional, to remove everything: delete %APPDATA%\Manage with Bunny (sign-in and app settings) and, on the host only, the storage folder you chose.

macOS

  1. Quit the app: click the bunny icon in the menu bar and choose Quit.
  2. Drag Manage with Bunny from Applications to the Trash.
  3. System Settings, General, Login Items: remove Manage with Bunny if it is listed.
  4. Optional, to remove everything: delete ~/Library/Application Support/Manage with Bunny (Finder, Go, Go to Folder) and, on the host only, the storage folder you chose.

Leaving a team but keeping the app: Settings, Leave workspace on this computer. On the host: Settings, Stop hosting (the data folder stays).

First-time setup

Set up your workspace

Pick the host computer

Use the owner's PC or any computer that stays on during work hours, connected to the office Wi-Fi or by cable. All messages and files are stored on it, so pick one with a big drive.

Host a workspace

On that computer open the app and choose Host a workspace. Enter the workspace name, your name, a username, a strong password, and choose the storage folder (a drive other than C: is suggested automatically).

Invite your team

The Home screen shows the join code. Press Copy invite: it copies the code and the host's address, so joining works even on networks that block discovery. Send it to your teammates.

Teammates join

Each person installs the app, chooses Join a team, pastes the invite and creates their own username and password. The app verifies the host's identity before sending anything.

Approve and set roles

A badge appears on Admin. Approve each request, pick their role (Manager, HR, Team Leader, Employee or your own custom positions) and who they report to. That builds the team chart.

Keep your password safe. Private messages are encrypted with it. If someone forgets theirs, an admin can create a one-time reset code (Admin, Members, Manage, Reset password), but older private messages cannot be recovered. That is what keeps them private.
Daily use

How the team works with it

Chat

  • New starts a direct message or a group. Employees can message their manager, teammates and people under them; managers and the owner can message anyone.
  • Click the microphone to record a voice message (up to 10 minutes), then Send voice.
  • Drag files into a chat, paste screenshots, or use the paper clip. Large videos stream right inside the chat.
  • One grey tick = sent, two blue ticks = seen. Under your last message you see Seen, Seen by ... or Not seen yet.
  • The search box finds chats and messages (Bengali and English). Click a result to jump to it.

Tasks

  • New task: title, details, links, due date, priority, and who it is for (yourself or anyone under you).
  • The person clicks Start, works, attaches the result and Submit for review.
  • The person who assigned it Approves or Requests changes with a note. Every step is recorded.
  • Delegate splits a task and passes parts further down the chain (e.g. manager to team leader to editor).
  • Filter by month to see any month's work; export the board to Excel or PDF.

Files

  • Everything shared in your chats and tasks, with search and filters for videos, images and documents.
  • Uploading a file with the same name again creates a new version; older versions stay available.
  • Admins see duplicates, old versions and storage use, and can clean up in one click.

Records, Performance, Reports

  • Work report: pick Today, 2, 3, 7, 30, 90 days, 6 months, 1 year or Custom; filter by person and client; see work, who gave it, hours, on time / late, quality stars, Drive links and files in one table.
  • Records: private sheets (who got which work, hiring, expenses, leads). Only you and people you share with can see them.
  • Performance: monthly score per person, hours logged, reviews. Managers rate their team each month.
  • Excel and PDF buttons on tasks, records, performance, work logs and the security log.

People who work from home

Remote teammates

Some people cannot be on the office Wi-Fi. Give them a remote profile so their work still lives with the rest of the team's data.

Create the profile

Admin, Members, Add remote profile: name, title, role, who they report to, and a caretaker (usually their team leader). The profile has no login.

Keep it updated

Assign tasks to them as usual. The caretaker sees "Start for Sara" and "Submit for Sara" and adds daily updates (hours, what was done, links) from the Home screen. History always shows who did it on whose behalf.

When they come to the office

Admin, Manage, Activate login gives a one-time code. On their computer: Join a team, paste the invite, I already have an account, then Use a reset code. They keep all their history.

Network

Staying connected

What the app does by itself

  • Finds the host with network announcements (broadcast and multicast), then by scanning the local network, then by the remembered addresses.
  • Reconnects automatically after Wi-Fi drops, sleep, a host restart or an IP address change.
  • Messages written while offline are sent when the connection returns. Uploads resume where they stopped.
  • The installer allows the app through Windows Firewall for devices on the same local network only, on Private and Public Wi-Fi alike.

If someone cannot connect

  1. Open Settings, Network check (or Check network on the yellow bar). It explains the problem and can repair the firewall rule in one click.
  2. Make sure both computers use the same, main Wi-Fi. Guest networks usually have AP / client isolation on, which blocks devices from seeing each other. No app can get around that; use the main network or turn isolation off in the router.
  3. Paste the full invite (code + address) when joining.
  4. Tip: reserve the host's IP address in the router (DHCP reservation).
Security

Private by design

Only your Wi-Fi

No cloud, no internet server. Joining needs the code and the owner's approval. All traffic is encrypted (TLS 1.3) and the app verifies the host's identity.

Private chats stay private

Direct messages are end-to-end encrypted. The host stores only scrambled data; not even the owner can read them. Passwords never leave your computer.

Everyone sees only their part

Every action is checked on the host. Employees cannot open other people's chats, tasks, records or files, or give themselves more power.

Turn on BitLocker on the host computer. Group chats, tasks, records and files are protected inside the app, but on the host's disk they are not encrypted. Anyone who can log in to that PC or take its drive could read them. On Windows: Settings, Privacy & security, Device encryption (or Control Panel, BitLocker Drive Encryption) and turn it on for the drive with the storage folder. On a Mac host: System Settings, Privacy & Security, FileVault.
"Windows protected your PC" / "unidentified developer". The installers are not code-signed yet. A code-signing certificate (Windows) and an Apple Developer ID (Mac) cost money every year. Until they are added, Windows SmartScreen and macOS Gatekeeper show a warning the first time; use More info, Run anyway on Windows and right-click, Open on Mac. Only download the app from the official Releases page.

Limitations

What it does not do (yet)

Network & hosting

  • Works only inside the same local network; there is no access over the internet. Remote people are handled with remote profiles kept up to date by a caretaker.
  • If the host computer is off or asleep, nobody can send or receive until it is back (nothing is lost).
  • One host per workspace; there is no automatic second host.
  • Guest Wi-Fi and routers with AP / client isolation block it completely.
  • No automatic updates: download and install new versions yourself.

Features

  • No voice or video calls and no screen sharing.
  • Windows and Mac only: no mobile app and no Linux build.
  • Search in private chats covers the newest 2,000 messages of each chat.
  • Executable files (.exe, .bat, .msi...) are blocked by default when sent on their own; zip them or ask an admin. Default maximum file size 50 GB (admin can raise it).
  • Folders arrive as a .zip; the receiver extracts it (double-click) to get the folder back.
  • Attendance check-in needs the app and the office network; there is no GPS or fingerprint check, so someone could check in for a colleague by using their signed-in computer.
  • Backups copy the database daily (14 kept); files are not duplicated, so copy the storage folder to another drive yourself.

Security

  • Group chats, tasks, records and files are not encrypted on the host's disk: turn on BitLocker / FileVault on the host.
  • Files and voice messages in private chats are access-controlled but not end-to-end encrypted (the text is).
  • If someone forgets their password, a reset code gives a new login but their old private messages cannot be read anymore.
  • Installers are not code-signed, so Windows / macOS warn on first run.
  • Security was tested internally (penetration test included); no outside company has audited it.

Tested range

  • Tested with 15 people at the same time and a year of data (300,000 messages, 25,000 tasks). Bigger teams should work but are not measured.
  • Tested with two app copies on one Windows PC; real multi-computer Wi-Fi depends on your router.
  • The Mac version is built and its tests pass on GitHub's Mac machines, but it has not yet been tried on a real Mac by us.
FAQ

Questions

What happens if the host computer is off?

Nobody can send or receive until it is back. Turn it on and everyone reconnects by themselves; nothing is lost. The host makes a database backup every day (Admin, Storage, Backups).

How many people can use it?

It was tested with 15 people chatting, sending files and working on tasks at the same time with zero errors, and with a year of data (300,000 messages, 25,000 tasks). Small and medium teams are comfortable.

How fast are file transfers?

As fast as your Wi-Fi: on a typical Wi-Fi 5/6 network a 1 GB file takes roughly 20-60 seconds. On cable it is faster. The app itself was measured far above Wi-Fi speed, so the network is the limit.

The app asked me to sign in again.

That happens only if the computer lost power right after the very first sign-in, or after a password reset. Just enter your password; your username is already filled in and you stay signed in after that.

Can I move the data to a bigger drive?

Yes: Admin, Storage, Move to another drive (on the host computer). Everyone stays connected.

Can I move the host to another computer?

Copy the whole storage folder to the new computer, install the app there and choose Host a workspace, Open existing data folder. Members reconnect automatically.
